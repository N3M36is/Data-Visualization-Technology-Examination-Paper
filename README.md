#dataset 10
แนวทางการใช้ชุดข้อมูล

ชุดข้อมูลนี้เป็นข้อมูลเชิงเปรียบเทียบ (Comparative Data) ที่ต้องการแสดงความแตกต่างของอุณหภูมิระหว่างเมืองต่าง ๆ

1. การวิเคราะห์ข้อมูล
   
สามารถใช้เพื่อ
เปรียบเทียบอุณหภูมิของแต่ละเมือง
หาเมืองที่ร้อนที่สุดหรือเย็นที่สุด
คำนวณค่าเฉลี่ยอุณหภูมิของทุกเมือง
วิเคราะห์สัดส่วนอุณหภูมิเมื่อเทียบกับผลรวมทั้งหมด

ตัวอย่างผลการวิเคราะห์
เมืองที่ร้อนที่สุด: Bangkok = 32°C
เมืองที่เย็นที่สุด: London = 18°C
ค่าเฉลี่ยอุณหภูมิ = (32+25+20+18+22)/5 = 23.4°C

2. การนำเสนอข้อมูล
   
ในไฟล์ app มีการใช้ Pie Chart เพื่อแสดงการกระจายตัวของอุณหภูมิแต่ละเมือง โดยใช้ฟังก์ชัน drawPieChart() และไลบรารี D3.js

คุณสมบัติของกราฟที่สร้างขึ้น
ใช้สีต่างกันสำหรับแต่ละเมือง
มี Tooltip แสดงชื่อเมือง อุณหภูมิ และเปอร์เซ็นต์เมื่อเลื่อนเมาส์ไปชี้
มี Animation ในการแสดงผลกราฟ
มี Legend อธิบายสีของแต่ละเมือง

#dataset 2
แนวทางการวิเคราะห์ข้อมูล
1. วิเคราะห์แนวโน้ม (Trend Analysis)
ข้อมูลแสดงให้เห็นว่ารายได้เพิ่มขึ้นอย่างต่อเนื่องทุกเดือน โดยเพิ่มขึ้นเดือนละ 500 หน่วย จาก 5,000 ในเดือนมกราคมเป็น 7,500 ในเดือนมิถุนายน

ข้อสังเกต:
รายได้เติบโตอย่างสม่ำเสมอ
ไม่มีช่วงที่รายได้ลดลง
สะท้อนถึงการเติบโตของธุรกิจหรือยอดขายที่ดีขึ้นอย่างต่อเนื่อง

2. คำนวณอัตราการเติบโต
รายได้เพิ่มจาก 5,000 เป็น 7,500
รายได้เติบโต 50% ภายใน 6 เดือน

3. หาค่าเฉลี่ยรายได้
รายได้เฉลี่ยเท่ากับ 6,250 หน่วยต่อเดือน

การนำชุดข้อมูลไปใช้

1. สร้างกราฟเส้น (Line Chart)
ในไฟล์ app มีการนำ Dataset 2 ไปแสดงเป็น กราฟเส้น Revenue Trend เพื่อแสดงการเปลี่ยนแปลงของรายได้ตามเวลา
ประโยชน์:
เห็นแนวโน้มการเติบโตได้ชัดเจน
เปรียบเทียบรายได้แต่ละเดือนได้ง่าย
ใช้ประกอบการตัดสินใจทางธุรกิจ

2. ใช้สร้าง Dashboard
สามารถนำข้อมูลไปแสดงใน:
Power BI
Tableau
D3.js
Excel Dashboard

#dataset 6
แนวทางการใช้ชุดข้อมูล
1. ทำความเข้าใจข้อมูล

ก่อนนำข้อมูลไปใช้ ควรศึกษา

วัตถุประสงค์ของชุดข้อมูล
แหล่งที่มาของข้อมูล
ความหมายของแต่ละตัวแปร (Features/Columns)
หน่วยวัดและรูปแบบข้อมูล
ข้อจำกัดหรืออคติที่อาจมีในข้อมูล

ตัวอย่าง

CustomerID	Age	Income	Purchase1001	25	30000	Yes

จากตัวอย่างต้องทราบว่า

Age = อายุ (ปี)
Income = รายได้ต่อเดือนหรือปี
Purchase = การตัดสินใจซื้อสินค้า
2. ตรวจสอบคุณภาพข้อมูล

ควรตรวจสอบ

ข้อมูลหาย (Missing Values)
ข้อมูลซ้ำ (Duplicate Data)
ค่าที่ผิดปกติ (Outliers)
รูปแบบข้อมูลไม่ถูกต้อง

ตัวอย่าง

อายุเป็น -5 ปี ถือเป็นค่าผิดปกติ
Email ว่างจำนวนมาก อาจต้องจัดการก่อนวิเคราะห์
3. เตรียมข้อมูล (Data Preparation)

กิจกรรมที่มักทำ ได้แก่

ลบข้อมูลที่ไม่จำเป็น
เติมค่าที่หายไป
แปลงรูปแบบข้อมูล
รวมชุดข้อมูลจากหลายแหล่ง
สร้างตัวแปรใหม่ (Feature Engineering)
4. วิเคราะห์ข้อมูล

นำข้อมูลไปใช้เพื่อ

วิเคราะห์แนวโน้ม
หาความสัมพันธ์ของตัวแปร
สร้าง Dashboard
สร้างรายงานสรุป

ตัวอย่างคำถาม

ลูกค้ากลุ่มใดซื้อสินค้ามากที่สุด?
ยอดขายเปลี่ยนแปลงอย่างไรในแต่ละเดือน?
ปัจจัยใดส่งผลต่อความพึงพอใจของลูกค้า?
5. ใช้ในการสร้างโมเดล AI / Machine Learning

ชุดข้อมูลสามารถนำไป

จำแนกประเภท (Classification)
พยากรณ์ค่า (Regression)
จัดกลุ่มข้อมูล (Clustering)
ตรวจจับความผิดปกติ (Anomaly Detection)
